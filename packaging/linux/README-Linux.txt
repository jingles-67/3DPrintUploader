3D Print Uploader for Linux
===========================

Ubuntu and Linux Mint:
  Install the .deb package by double-clicking it, or run:
  sudo apt install ./3D-Print-Uploader-*-Ubuntu-LinuxMint-*.deb

Other Linux distributions:
  Extract the portable .tar.gz archive and run 3d-print-uploader.

Your settings and credentials are stored in:
  $XDG_CONFIG_HOME/3d-print-uploader
or, when XDG_CONFIG_HOME is not set:
  ~/.config/3d-print-uploader

On first launch, open the Tutorial page and import your own Google Desktop-app
OAuth credentials. No personal credentials are included in these packages.
