# Changelog

## 1.2.0

- Added Ubuntu and Linux Mint `.deb` packaging.
- Added a portable archive for other Linux distributions.
- Added a macOS `.app` and `.dmg` build.
- Added a credential-free source archive for other platforms.
- Added automatic multi-platform builds and GitHub Release uploads.
- Moved packaged Linux and macOS user data to writable per-user folders.
- Added platform-specific icons and source launch commands.

## 1.1.1

- Added automatic patch versioning for updates.
- Added a per-user NSIS Windows installer.
- Added first-run setup instructions and credential import.
- Removed bundled personal Google, Drive, and Beacons configuration.
- Made the system appearance the default theme.
